Methodology & Documentation

How EndoRisk works — completely in the open.

EndoRisk is an independent, browser-based educational tool that visualizes endocrine risk factors across four conditions. This page documents exactly what it does, what rules drive every number, what published references those rules are anchored to, and — just as importantly — what the tool deliberately does not claim. Everything here is meant to be inspectable; there is no hidden model and nothing to take on faith.

✓What this is

  • ›A transparent, rule-based scoring engine that maps biomarkers and symptoms onto four endocrine conditions.
  • ›An interactive teaching and visualization tool grounded in published clinical reference ranges.
  • ›A self-contained web app — all computation is local; no patient data is transmitted or stored.

✕What this is not

  • ›Not a trained machine-learning classifier. The weights are hand-specified for illustration, not learned from data.
  • ›Not validated against patient outcomes, and it reports no accuracy, sensitivity, specificity, or AUC.
  • ›Not a medical device and not for diagnosis, screening, or any clinical decision.

The scoring approach

Each condition gets its own score from a small set of relevant biomarkers. The method is intentionally simple and legible: for each input we measure how far the value sits from a clinical reference midpoint (a standardized distance), multiply those distances by hand-chosen weights that reflect the relative clinical importance of each marker, sum them, and pass the total through a logistic (sigmoid) function to land on a 0–100% index. Relevant symptoms add small fixed increments.

This is the same mathematical shape as logistic regression, but the coefficients here were set by hand to encode textbook clinical relationships — they were not fit to a labeled dataset, and the output is an illustrative index, not a calibrated probability of disease. The tables under each model below show the actual weights the app uses, so you can trace any score back to its inputs.

01

Input

Twelve clinical biomarkers entered via live sliders, each bounded and labeled with its reference range.

02

Standardize

Each value is converted to a signed distance from its clinical reference midpoint, scaled by a representative spread.

03

Weight

The standardized inputs (and any selected symptoms) are combined using the hand-specified coefficients listed below.

04

Transform

A logistic function maps the weighted sum into a bounded 0–1 index, capped to a 1–99% display range.

05

Stratify

The index is banded — Low (<25%), Moderate (25–50%), Elevated (>50%) — and used to drive the visualization.

Limitations

These constraints are inherent to the design and matter for understanding what the tool can and cannot tell you.

  • ▸Hand-specified, not learned. Coefficients were chosen to reflect textbook relationships, not estimated from outcome data, so the indices are illustrative rather than calibrated probabilities.
  • ▸No validation. The tool has never been tested against real patient outcomes; no sensitivity, specificity, or discrimination statistics exist or are claimed.
  • ▸Single-snapshot, isolated markers. Real endocrine diagnosis integrates dynamic testing, antibodies, imaging, and clinical context that this model does not represent.
  • ▸Population-agnostic. Reference ranges vary by age, sex, assay, pregnancy, and lab; the fixed midpoints here are generic.
  • ▸Educational scope only. EndoRisk is not a medical device and must never inform diagnosis, screening, or treatment decisions.
